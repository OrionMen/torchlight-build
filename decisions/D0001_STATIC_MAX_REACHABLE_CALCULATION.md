# D0001 采用可达最大值静态计算

## 决定

第一阶段不实现完整 Runtime Simulator。对于战意、祝福、迷踪及类似需要先获取的机制：

- 没有有效获取来源：按 0 计算。
- 有有效获取来源：按当前配装计算出的有效最大值计算。
- 暂不向玩家开放手动层数或覆盖率调整。

## 原因

完整运行时需要处理移动、命中、怪物行为、状态获得速度、衰减、持续时间和快照等大量问题，会把项目扩张为完整游戏模拟器。静态最大值更符合当前“分析和比较 BD 理论强度”的目标。

## 后果

- 输出必须标记为理论最大值计算。
- 获取能力与上限修改必须分开建模。
- 后续若增加手动或模拟模式，不得破坏当前默认策略。
